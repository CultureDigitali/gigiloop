**Title:** GigiLoop: a verification-first autonomous coding skill (OpenCode)
**Tags:** ai, programming, release, devtools

**Description (keep it dry — Lobsters hates hype):**
GigiLoop is an OpenCode skill that wraps an autonomous edit→test→review loop with an evidence
gate. Every quality score (0–10) must reference a test, command output, or code location; a
confirmed flaw can lower the score before completion; and the loop only finishes when all
acceptance criteria clear a threshold. It includes a reproducible benchmark protocol comparing
one-pass, naive-loop, and GigiLoop from the same commit. MIT licensed.
